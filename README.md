# 📚 Academic Planner & Deadline Tracker

> A comprehensive web application to help students manage their academic deadlines, track assignments, and never miss important dates again!

## 🎯 The Problem We're Solving

Students face numerous challenges in managing their academic life:
- ❌ Missing assignment deadlines
- ❌ Difficulty tracking multiple course deadlines
- ❌ No centralized place for syllabus and important dates
- ❌ Forgetting exam dates and project submissions
- ❌ Poor time management leading to last-minute panic

## ✨ Features

- 📅 **Deadline Dashboard**: View all upcoming deadlines at a glance
- 📚 **Course Management**: Organize deadlines by course/subject
- ⏰ **Smart Reminders**: Get notified before deadlines
- 📊 **Progress Tracking**: Track completion status of assignments
- 🎨 **Priority Levels**: Mark tasks by urgency (High, Medium, Low)
- 🔍 **Search & Filter**: Easily find specific assignments or courses
- 📱 **Responsive Design**: Works on desktop, tablet, and mobile
- 💾 **Local Storage**: Your data persists across sessions
- 📈 **Statistics**: View your productivity and completion rates

## 🛠️ Tech Stack

- **HTML5** - Structure and semantics
- **CSS3** - Styling with modern features (Grid, Flexbox, Animations)
- **JavaScript (ES6+)** - Interactive functionality and data management
- **Local Storage API** - Data persistence

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code recommended)
- Basic knowledge of HTML, CSS, and JavaScript

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/academic-planner.git
cd academic-planner
```

2. Open `index.html` in your browser or use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (with http-server package)
npx http-server
```

3. Navigate to `http://localhost:8000` in your browser
